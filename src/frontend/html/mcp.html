Overview

VARUN.SURF exposes a Model Context Protocol server so AI assistants can look up kite spots, forecasts, and live wind conditions as tools. The server is public and requires no authentication.

Available Tools

list_spots Lists all kite spots tracked by varun.surf, grouped by country, with their Windguru spot IDs.
get_spot Returns full details for a single spot: overview, current wind conditions, daily and hourly forecasts, and external links.
get_wind_forecast Returns the hour-by-hour wind forecast for a single spot: wind, gusts and direction for every hour, with the windiest hour and the kiteable ones called out.
find_spot_by_name Finds spots whose name contains the given query (case-insensitive).
find_windy_spots Searches every spot at once for the ones reaching a given wind speed in the hours ahead, with the windy hours, peak wind, gusts and direction.
list_countries Lists all countries with at least one kite spot and the number of spots per country.
get_spots_by_country Lists all kite spots in a country identified by its slug, e.g. poland.
get_status Returns a short service summary: number of spots, countries and active live weather stations.

Command-line client (CLI)

The same answers in a terminal: varun tells you when it will blow at a spot and where to go, with live conditions, favourites and output for scripts (--json) or LLM pipelines (--format md). It runs on Linux (x86_64, arm64) and macOS on Apple Silicon; the installer checks the download's checksum and needs no sudo.

Install
-
Examples
varun wind jastarnia            # hour-by-hour wind at one spot
varun windy --country poland    # where it will blow in the next 24 h
varun now                       # live conditions at your favourites
varun spot tarifa --model ifs   # everything about one spot

All commands and options are described in the CLI README; binaries for a manual install are on GitHub Releases.

llms.txt

If your AI assistant cannot speak MCP, the same data is available as plain Markdown. VARUN.SURF publishes an llms.txt file describing the service, its data sources and the Markdown endpoints listed below. All of them are public, need no session cookie and no authentication, and are free to fetch, crawl or index.

llms.txt
-
Markdown endpoints
/llms.txt Service overview, data sources, API access and links to the Markdown endpoints below.
/llms/spots.md Index of all kite spots with their countries and links to the per-spot documents.
/llms/spots/{wgId}.md Single spot: overview, current conditions, daily and hourly forecast, and external links.
/llms/spots/{wgId}/wind.md Hour-by-hour wind, gusts and direction for a single spot. Query parameters: hours and minWind.
/llms/wind.md Every spot reaching a given wind speed in the hours ahead, strongest first. Query parameters: minWind, hours, country and limit.
/llms/countries.md Index of all countries with the number of spots in each.
/llms/countries/{slug}.md Spots in a single country, where the slug is the lowercased country name with spaces replaced by hyphens, e.g. poland or czech-republic.
