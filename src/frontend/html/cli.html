Command-line client (CLI)

The same answers in a terminal: varun tells you when it will blow at a spot and where to go, with live conditions, favourites and output for scripts (--json) or LLM pipelines (--format md). It runs on Linux (x86_64, arm64) and macOS on Apple Silicon; the installer checks the download's checksum and needs no sudo.

Examples
varun wind jastarnia                  # hour-by-hour wind at one spot
varun wind puck --min-wind 15         # only the hours reaching 15 kts
varun wind jastarnia --all            # with temperature, rain, cloud and waves
varun wind jastarnia --units ms       # wind in m/s
varun windy --country poland          # where it will blow in the next 24 h
varun windy --min-wind 20 --hours 48  # spots reaching 20 kts within two days
varun now                             # live conditions at your favourites
varun now jastarnia puck              # live conditions at the spots you name
varun now --watch                     # the same, redrawn every minute
varun spot jastarnia --model ifs      # everything about one spot
varun spot jastarnia --models         # forecast models available at a spot
varun search hel                      # spots whose name contains a word
varun fav add jastarnia --as home     # save a favourite under a short name
varun wind home --json | jq .summary  # JSON for scripts
varun windy | cut -f1,7               # plain columns in a pipe: spot and peak
varun spot jastarnia --format md      # Markdown for LLM pipelines

All commands and options are described in the CLI README; binaries for a manual install are on GitHub Releases.
