Command-line client (CLI)

The same answers in a terminal: varun tells you when it will blow at a spot and where to go, with live conditions, favourites and output for scripts (--json) or LLM pipelines (--format md). It runs on Linux (x86_64, arm64) and macOS on Apple Silicon; the installer checks the download's checksum and needs no sudo.

-
Examples
varun wind jastarnia            # hour-by-hour wind at one spot
varun windy --country poland    # where it will blow in the next 24 h
varun now                       # live conditions at your favourites
varun spot tarifa --model ifs   # everything about one spot

All commands and options are described in the CLI README; binaries for a manual install are on GitHub Releases.
