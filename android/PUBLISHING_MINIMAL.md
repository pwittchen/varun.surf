# Publishing on Google Play: the minimum

This is only what Google Play requires before `surf.varun.app` can go live, with nothing
optional. The full plan is in [PUBLISHING.md](PUBLISHING.md).

## 1. Account
- [ ] Play Console developer account ($25) with identity verified and a contact email
- [ ] **New personal account (created after 13 Nov 2023):** a closed test with **12 or more
      testers opted in for 14 days in a row** before you can apply for production access.
      Organisation accounts don't need this

## 2. Privacy policy (blocker)
- [ ] A public page such as `https://varun.surf/privacy`. Play requires a policy for every app,
      and in particular for apps that request location. It must load without the session cookie.
      It should say:
      - nothing personal is collected
      - location is used only on the device
      - IP addresses reach varun.surf and the map tile servers
      - AI text is generated by OpenAI from forecast data only
      - a contact email

## 3. App changes (blockers)
- [ ] **A way to report AI output** (Play's AI-Generated Content policy): a "Report" action under
      the AI analysis and the ICM reading, with EN and PL strings. It can be as simple as a
      prefilled email
- [ ] AI and ICM work in production, or the buttons are hidden when the feature is off. Without
      this, a reviewer gets a 503 after confirming, which reads as a broken feature

## 4. Build and upload
- [ ] Signed release AAB (`VARUN_*` env vars, `./gradlew bundleRelease`) with versionName 1.0.0
- [ ] The release build tried on a real phone with R8 on
- [ ] Create the app in Play Console: free, default language English, Play App Signing on
- [ ] **Upload the first AAB by hand** to Internal testing. The API can't create the first release
- [ ] CI is only needed for later releases. Until the first publish, the upload step needs
      `status: draft`; with `completed` the Play API rejects the upload

## 5. App content declarations (Policy → App content)
- [ ] Privacy policy URL
- [ ] App access: no login needed
- [ ] Ads: none
- [ ] Content rating questionnaire filled in (expected: Everyone / PEGI 3)
- [ ] Target audience: 13+ (no children, which keeps the Families policy out)
- [ ] Data safety: no data collected, no data shared, encrypted in transit
- [ ] News, health, financial and government declarations: all "No"

## 6. Store listing (English is enough to start)
- [ ] App name (≤ 30 chars), short description (≤ 80), full description (≤ 4000)
- [ ] Icon: 512 × 512 PNG
- [ ] Feature graphic: 1024 × 500
- [ ] Phone screenshots: at least 2 (in practice 4), 9:16, real data only
- [ ] Category Weather, contact email

## 7. Go live
- [ ] Closed test finished (if required by section 1), then apply for production access
- [ ] Promote the release to Production and wait for review (up to about 7 days)

## Can wait until after launch
These are in [PUBLISHING.md](PUBLISHING.md):
- `assetlinks.json`: until it exists, `varun.surf` links open in the browser instead of the app
- Polish listing and tablet screenshots
- R8 mapping, native debug symbols and release notes in CI
- Baseline profile
- Staged rollout, vitals thresholds, Play badge on the website
